# Atividade 7 — Patch 23.26.1 → 23.26.2 com AutoUpgrade

## Contexto
Com o banco já em 23.26.1 (Atividade 6), esta atividade aplica o próximo Release Update (23.26.2) via AutoUpgrade, criando um novo Oracle Home patchado e movendo o banco para ele.

## Pré-requisitos
- Banco ORCL rodando em Oracle 23.26.1 no `${ORACLE_HOME_23AI}`
- Gold Image completa 23.26.2 disponível em `${INSTALL_DIR}/${GOLD_IMAGE_23AI_PATCHED}`
- autoupgrade.jar versão 23.x
- Espaço em `/u01` (~7 GB para novo Oracle Home)

> **Nota sobre o arquivo do 23.26.2**: o arquivo disponibilizado para esta atividade (`p39099680_230000_Linux-x86-64.zip`) tem nome no padrão de patch OPatch (`p########_versão_plataforma.zip`), mas **é uma Gold Image completa** (contém `bin/`, `rdbms/`, `dbs/`, etc. na raiz do zip — não a estrutura de um patch isolado). Usar sempre a **Fase 2.2 Opção A** (extração direta), não a Opção B (clone + opatch apply).

## Carregar variáveis

Leia `.env` com o Read tool. Nunca exiba senhas.

Definir variáveis adicionais:
```bash
ORACLE_HOME_23AI_PATCHED=/u01/app/oracle/product/23.0.0/dbhome_2
SSH="ssh -i ${SSH_KEY} -o StrictHostKeyChecking=no -o LogLevel=ERROR \
  -o ServerAliveInterval=30 -o ServerAliveCountMax=3 oracle@${VM_IP}"
SSH_ROOT="ssh -i ${SSH_KEY} -o StrictHostKeyChecking=no -o LogLevel=ERROR \
  -o ServerAliveInterval=30 -o ServerAliveCountMax=3 root@${VM_IP}"
# AutoUpgrade 26.x requer Java 11 — usar o JDK embutido no Oracle Home 23ai
JAVA="${ORACLE_HOME_23AI}/jdk/bin/java"
```

## FASE 0 — Pré-verificações

### 0.1 — Verificar FRA antes do patch

O datapatch gera redo. Garantir margem na FRA.

```bash
${SSH} "
export ORACLE_HOME=${ORACLE_HOME_23AI}
export ORACLE_SID=CDBORCL
export PATH=\$ORACLE_HOME/bin:\$PATH
sqlplus -s / as sysdba << 'EOF'
SELECT ROUND(space_used/space_limit*100,1) AS fra_pct,
       ROUND(space_limit/1073741824,1) AS limit_gb
FROM v\$recovery_file_dest;
EOF
"
```

Se `fra_pct > 70%`, expandir: `ALTER SYSTEM SET db_recovery_file_dest_size = 25G SCOPE=BOTH;`

### 0.2 — Confirmar versão atual 23.26.1

### 0.3 — Limpeza preventiva de jobs anteriores do AutoUpgrade (padrão, sempre executar)

> **PADRÃO OBRIGATÓRIO** (ver CLAUDE.md § Regras Operacionais): antes de QUALQUER `-mode analyze`/`-mode deploy`, descobrir e limpar o job mais recente do SID `CDBORCL` — não esperar o erro "unfinished execution" para só então reagir.

```bash
${SSH} "
LAST_JOB=\$(ls -td ${AUTOUPGRADE_LOG_DIR}/CDBORCL/CDBORCL/*/ 2>/dev/null | head -1 | xargs -n1 basename 2>/dev/null)
echo \"Ultimo job encontrado para SID CDBORCL: \${LAST_JOB:-nenhum}\"
if [ -n \"\$LAST_JOB\" ]; then
  export ORACLE_HOME=${ORACLE_HOME_23AI}
  export ORACLE_SID=CDBORCL
  export PATH=\$ORACLE_HOME/bin:\$PATH
  ${JAVA} -jar ${AUTOUPGRADE_JAR} -config ${INSTALL_DIR}/autoupgrade_patch23262.cfg -clear_recovery_data -jobs \$LAST_JOB 2>&1 | tail -5
fi
"
```

(`-clear_recovery_data` retornando "not found" é inofensivo. Se o `.cfg` ainda não existir nesta primeira passada, repetir este passo logo após criá-lo na Fase 3.1.)

## FASE 3 — Mover banco para novo home com AutoUpgrade

### 3.1 — Criar config de patch 23.26.2

```bash
${SSH} "
cat > ${INSTALL_DIR}/autoupgrade_patch23262.cfg << 'EOF'
global.autoupg_log_dir=${AUTOUPGRADE_LOG_DIR}

upg1.source_home=${ORACLE_HOME_23AI}
upg1.target_home=/u01/app/oracle/product/23.0.0/dbhome_2
upg1.sid=CDBORCL
upg1.run_utlrp=yes
upg1.timezone_upg=yes
upg1.target_version=${ORACLE_23AI_PATCH_VERSION}
EOF
chown ${ORACLE_USER}:${ORACLE_GROUP} ${INSTALL_DIR}/autoupgrade_patch23262.cfg
cat ${INSTALL_DIR}/autoupgrade_patch23262.cfg
"
```

### 3.2 — Analisar

```bash
${SSH} "su - ${ORACLE_USER} -c '
export ORACLE_HOME=${ORACLE_HOME_23AI}
export ORACLE_SID=CDBORCL
export PATH=\$ORACLE_HOME/bin:\$PATH

${JAVA} -jar ${AUTOUPGRADE_JAR} \
  -config ${INSTALL_DIR}/autoupgrade_patch23262.cfg \
  -mode analyze
' 2>&1 | tail -20"
```

### 3.3 — Deploy em background

O deploy leva 15-25 minutos. Rodar com nohup para evitar perda por queda de SSH.

```bash
${SSH} "
export ORACLE_HOME=${ORACLE_HOME_23AI}
export ORACLE_SID=CDBORCL
export PATH=\$ORACLE_HOME/bin:\$PATH

mkdir -p ${INSTALL_DIR}/logs
nohup ${JAVA} -jar ${AUTOUPGRADE_JAR} \
  -config ${INSTALL_DIR}/autoupgrade_patch23262.cfg \
  -mode deploy \
  -noconsole > ${INSTALL_DIR}/logs/autoupgrade_patch23262.log 2>&1 &
echo \"AutoUpgrade PID=\$! — Log: ${INSTALL_DIR}/logs/autoupgrade_patch23262.log\"
"
```

Monitorar progresso:
```bash
${SSH} "tail -15 ${INSTALL_DIR}/logs/autoupgrade_patch23262.log 2>/dev/null"
```

## FASE 4 — Verificação pós-patch

### 4.1 — Confirmar versão 23.26.2

```bash

export ORACLE_HOME=/u01/app/oracle/product/23.0.0/dbhome_2

```

### 4.2 — utlrp com Resource Manager desabilitado

```bash
${SSH} "
export ORACLE_HOME=/u01/app/oracle/product/23.0.0/dbhome_2
export ORACLE_SID=CDBORCL
export PATH=\$ORACLE_HOME/bin:\$PATH

sqlplus -s / as sysdba << 'EOF'
ALTER PLUGGABLE DATABASE ORCLPDB OPEN;
ALTER PLUGGABLE DATABASE ORCLPDB SAVE STATE;
ALTER SYSTEM SET resource_manager_plan='' SCOPE=BOTH;
EOF

nohup sqlplus -s / as sysdba > /tmp/utlrp_23262.log 2>&1 << 'EOF' &
ALTER SESSION SET CONTAINER=CDB\$ROOT;
@?/rdbms/admin/utlrp.sql
ALTER SESSION SET CONTAINER=ORCLPDB;
@?/rdbms/admin/utlrp.sql
EOF
echo \"utlrp PID=\$!\"
"
```

Verificar (após ~5 min):
```bash
${SSH} "grep -A2 'OBJECTS WITH ERRORS\|ERRORS DURING' /tmp/utlrp_23262.log 2>/dev/null"
```

```bash
ORACLE_HOME_23AI_PATCHED=/u01/app/oracle/product/23.0.0/dbhome_2

```

### 4.4 — Atualizar .bash_profile do oracle

```bash

ORACLE_HOME_23AI_PATCHED=/u01/app/oracle/product/23.0.0/dbhome_2
sed -i \"s|export ORACLE_HOME=.*|export ORACLE_HOME=\${ORACLE_HOME_23AI_PATCHED}|\" ~/.bash_profile
sed -i 's|export ORACLE_SID=.*|export ORACLE_SID=CDBORCL|' ~/.bash_profile
grep -E 'ORACLE_HOME|ORACLE_SID' ~/.bash_profile

```

### 4.5 — Atualizar serviços systemd

```bash
${SSH_ROOT} "
ORACLE_HOME_23AI_PATCHED=/u01/app/oracle/product/23.0.0/dbhome_2
for svc in oracle-database.service oracle-listener.service; do
  [ -f /etc/systemd/system/\$svc ] && \
    sed -i \"s|${ORACLE_HOME_23AI}|\${ORACLE_HOME_23AI_PATCHED}|g\" /etc/systemd/system/\$svc
done
systemctl daemon-reload
echo 'systemd atualizado para dbhome_2 (23.26.2)'
systemctl is-active oracle-database
"
```

### 4.6 — Reconfirmar OPEN + SAVE STATE da PDB (após datapatch/systemd)

O `datapatch`/restart via systemd pode ter alterado o estado — reconfirmar o padrão (OPEN + SAVE STATE sempre juntos, idempotente):

```bash
${SSH} "
export ORACLE_HOME=/u01/app/oracle/product/23.0.0/dbhome_2
export ORACLE_SID=CDBORCL
export PATH=\$ORACLE_HOME/bin:\$PATH
sqlplus -s / as sysdba << 'EOF'
ALTER PLUGGABLE DATABASE ORCLPDB OPEN;
ALTER PLUGGABLE DATABASE ORCLPDB SAVE STATE;
SELECT name, open_mode FROM v\$pdbs;
EOF
"
```
